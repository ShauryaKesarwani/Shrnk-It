# Shrnk It mobile

Android-first Flutter app for local media compression. The web target is for UI development; Android media access, compression, and restore require an Android device and are not implemented yet.

Run `flutter pub get`, then `flutter run -d chrome` for the web UI. Build and test Android on a machine with the Android SDK installed. See [PROJECT_PLAN.md](PROJECT_PLAN.md) for the agreed workflows and outstanding work.
