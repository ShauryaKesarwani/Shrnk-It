# Project documentation

This folder contains concise, human- and AI-readable project documentation. Update relevant Markdown files when project behavior or guidance changes.

## Where to look

- `PROJECT_PLAN.md` (at the repository root, when present): project goals, scope, and planned work. Refer to it for product direction and roadmap context; it is not present yet.
- `Todo.md` (at the repository root): task tracking using `[ ]` pending, `[~]` in progress, and `[x]` done.
- `AGENTS.md` (at the repository root): engineering collaboration and implementation expectations.
- Other Markdown files in this folder: topic-specific project details; prefer the relevant topic doc for implementation specifics.
